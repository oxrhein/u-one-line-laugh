A single original one-line joke for the make.fun bounty **One Line, One Laugh**. The program writes the joke to `entry.txt` — one line, 68 characters, no setup, the twist lands on a single read.

> My AI wrote my apology email so well that even I believe I meant it.

## Run

```sh
python3 main.py
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default).
